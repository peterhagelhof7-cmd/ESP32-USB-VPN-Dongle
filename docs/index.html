ESP32-USB-VPN-Dongle

Firmware direkt aus dem Browser installieren – für Wemos S2 Mini und ESP32-S3-DevKitC-1 N16R8. Version …

Installieren

Dieser Browser kann kein Web Serial. Bitte Chrome, Edge oder Opera am Desktop verwenden (nicht Firefox, Safari, iPhone/iPad).
Web Serial geht nur über HTTPS – diese Seite direkt über GitHub Pages öffnen.

Der Flasher erkennt S2 oder S3 selbst und spielt die passende Firmware auf. Beim ersten Mal „Gerät löschen“ anhaken.

ESP32-S3-DevKitC-1

  1. USB-Kabel an den Port UART stecken (nicht „USB“).
  2. Installieren → den Port wählen (CP210x / „USB to UART“).
  3. Nach dem Flashen das Kabel an den Port USB umstecken – der PC sieht einen neuen Netzwerkadapter.

Wemos S2 Mini

  1. In den Download-Modus: Taste 0 (BOOT) gedrückt halten, RST kurz drücken, BOOT loslassen.
  2. Installieren → den neu erschienenen Port wählen („ESP32-S2“).
  3. Nach dem Flashen einmal RST drücken – der S2 startet nicht von selbst neu und meldet sich danach als Netzwerkadapter.
Zum erneuten Flashen eines S2 immer zuerst in den Download-Modus – im Betrieb ist er ein Netzwerkadapter, kein serieller Port.

Danach

Windows/macOS melden „Anmeldung im Netzwerk erforderlich“ → draufklicken oder http://192.168.226.1/ öffnen → WLAN einrichten. Einstellungen: admin / admin – sofort ändern.

Updates später ohne Flasher: Weboberfläche → Firmware-Update (OTA) mit der .bin aus den Releases.
